Future Scope

What this project does today, how it is built, and where it can go next.

The project in one paragraph

Sentiment is a full-stack web application that reads text and emoji and tells you whether the feeling behind it is positive, negative or neutral — with the probability of each class shown as a pie chart. A fine-tuned HuggingFace sequence-classification checkpoint does the prediction; a Python FastAPI backend serves it, and a static, build-free frontend provides the chat-style interface.

How a request flows

Text / emoji→FastAPI→Sentiment model→Scores & insight→Pie chart
Photo / short video→Extract text (OCR)→Sentiment model→Pie chart

Technology

  • Model: HuggingFace Transformers + PyTorch, loaded once at server start.
  • Backend: Python, FastAPI, SQLAlchemy (SQLite for local use, Postgres-ready), JWT session cookie, bcrypt.
  • Media: Tesseract OCR with OpenCV frame sampling for video.
  • Frontend: plain HTML, CSS and JavaScript with Chart.js — no build step.
  • Deployment: backend as a Docker container; frontend on Vercel with an /api rewrite so the session cookie stays first-party.

Where it can go next

These are directions for future work, not features that exist today.

Next

MCP server

Expose the model as an MCP tool so other AI assistants can call the sentiment analysis directly.

Next

Research paper

Document the model, the data and the evaluation in a written paper linked from the home page.

Next

Speech & scene understanding

Transcribe a video's audio and use an image-captioning model, so photos and clips without visible text can be analysed too.

Next

More languages

Multilingual models and OCR language packs for non-English text and emoji usage.

Next

Aspect-level sentiment

Break a long review into topics (price, support, quality) and score each one separately.

Next

Explainability

Highlight the words and emoji that pushed the prediction toward a class.

Next

Trends & reports

Sentiment over time across a user's chats, with exportable reports.

Next

MLOps

Automated tests and deployment, experiment tracking, and monitoring for model drift in production.

Next

Public API

API keys and rate limits so other applications can integrate the service safely.
